# Plan: Basic functionality (2026-10-24)

Goal: paste a YouTube link → the video appears → it gets split into chapters
using its subtitles → chapter lengths can be adjusted → any chapter can be looped.

We build it in small steps. After each step the page should still work, and you
should check it in the browser before moving on.

---

## Important note about subtitles

A plain website **can't download subtitles from YouTube automatically**.
YouTube blocks other websites from doing that. So we use a simple workaround:
you get the subtitles yourself and paste them into the page.

Two easy ways to get them:

- **Copy from YouTube:** under the video, click **...more → Show transcript**,
  then select and copy the text. Each line comes with a timestamp, like `0:12`.
- **Download an `.srt` file:** use a subtitle download website, then open the
  file and copy its contents.

The page will understand both formats.

---

## Step 0: Decide how to open the page

The app is a **static page**: just HTML, CSS and JavaScript files, with no server
code. There are two ways to open it:

- **Double-click `index.html`** (easiest). The catch: YouTube sometimes refuses
  to play videos in pages opened straight from a file (you'd see "Error 153").
- **Put it on GitHub Pages** (free static hosting). You get a real web address,
  YouTube plays normally, and it works on your iPhone too. There's nothing to
  run or maintain. You upload the files and GitHub shows them.
